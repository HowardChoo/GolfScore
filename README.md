# 골프 스코어카드

라운드 중에 휴대폰으로 샷(클럽·결과·구질)과 퍼팅을 기록하고, 끝나면 엑셀 Summary 시트에 붙여 넣는 웹앱.
서버 없이 동작하는 정적 웹(PWA)이라 GitHub Pages에 올려 쓴다. 외부 패키지 없음.

## 파일

- `index.html`, `style.css`, `app.js` — 화면
- `logic.js` — 스코어·통계 계산과 엑셀 내보내기 (DOM 없음, Node에서도 불러올 수 있음)
- `sw.js` — 오프라인 캐시. **앱 파일을 고치면 `VERSION`을 올려야** 휴대폰에 새 버전이 들어간다
- `courses.csv` — 기본 골프장·코스 목록 (`COUNTRY_CLUB,COURSE,HOLE1~HOLE9,PAR_TOTAL`, UTF-8). 라운드 설정에서 골프장·코스를 고를 수 있게 된다. 이 기기에 저장된 같은 코스가 있으면 그쪽 파가 우선. 고친 뒤에는 `sw.js`의 `VERSION`도 올린다
- `manifest.webmanifest`, `icons/` — 홈 화면 아이콘

## 기록 규칙 (엑셀 Dictionary 시트 기준)

- 클럽 `D W3 W5 U4 I4~I9 PW FW SW`, 결과 `FW RG HZ OB BK FR GR`, 구질 `ST↑ SL→ PS↗ HK← PU↖ FA↓ TO↕`
  (클럽 FW와 결과 FW는 칸(CB/RT)이 달라 구분된다. 예전 버전에서 AW로 적은 클럽은 불러올 때 FW로 바뀐다)
- 퍼팅은 샷으로 적지 않고 퍼팅 수만 누른다
- 스코어 = 샷 수 + 퍼팅 + 벌타
- 벌타 자동: OB 2, HZ 1 (홀 화면에서 직접 고칠 수 있음)
- GIR 자동: 그린(GR)에 올라간 타수(벌타 포함) ≤ 파 − 2
- 샌드세이브 자동: 샷 결과에 BK가 있으면 파 이하 O, 보기 이상 X, 없으면 - (탭해서 고칠 수 있음)
- FHR(FW 안착률): 파4·파5 티샷(1ST) 결과(RT)가 FW인 비율. 파3은 뺀다 (엑셀 Raw의 FHR 수식과 같음)
- 구질 비율: 구질을 기록한 모든 샷 중 해당 구질의 비율 (티샷만이 아님, 구질을 생략한 샷은 빼고 계산)

## 엑셀로 옮기기

라운드 요약 화면 맨 아래 **메일로 보내기 (CSV 첨부)** → 공유 창에서 Gmail·메일 앱 선택 → 받는 사람에 내 메일.
첨부되는 CSV 3개:

- `_summary.csv` — Summary 시트 A~AB 28칸. PC에서 열어 행을 복사한 뒤 Summary 시트 다음 빈 행 A열에 붙여 넣기
- `_round.csv` — Summary에 없는 코스명·날씨·동반자별 스코어·비용 항목·메모 3줄
- `_shots.csv` — 한 샷당 1행. 클럽별 분석·백업용

동반자 이름·비용·메모 같은 개인 정보도 모두 들어간다. 앱 자체는 서버로 아무것도 보내지 않는다 (날씨 조회 때 위치 좌표만 Open-Meteo로 전송).

라운드 번호(Summary B열)는 입력하지 않고, 앱에 있는 같은 해 라운드를 날짜·티타임 순으로 세어 매긴다.

## 휴대폰에 설치

GitHub Pages 주소를 연 뒤

- iPhone Safari: 공유 버튼 → **홈 화면에 추가**
- Android Chrome: ⋮ 메뉴 → **홈 화면에 추가** (또는 앱 설치)

한 번 열어 두면 인터넷이 없어도 기록할 수 있다 (날씨 불러오기만 인터넷 필요).

## 데이터 보관

기록은 그 휴대폰 브라우저 저장소에만 있다. 홈 화면의 **백업 파일 저장**으로 가끔 백업해 두고,
휴대폰을 바꾸면 **백업 복원**으로 옮긴다. iPhone은 홈 화면에 추가해서 쓰는 것이 데이터가 더 오래 유지된다.

## 로컬에서 확인

```
python -m http.server 8000
```

후 `http://localhost:8000` (서비스 워커는 localhost나 https에서만 동작).
